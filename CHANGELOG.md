# Changelog

## 0.1.0 — v0.1

Initial public research preview, built in response to BLA.

- Bounded CLI, programmatic API, stdio MCP server and bundled agent skill.
- Original-byte identities, source ranges, evidence records and explicit UNKNOWN outcomes.
- JavaScript/TypeScript inspection and normalization, ASAR member views, native layouts, WASM, SQLite and model-container inspection.
- Opt-in JavaScript inspection sidecars with exclusive writes and completion/hash verification.
- Portable product tests separated from provider-dependent research qualification.
- Pinned BLA/REA source inventory and published coverage limits, including the fresh-agent baseline result.

The release does not claim universal recovery, full equivalence or an incremental agent recovery win. See [coverage](docs/COVERAGE.md).
