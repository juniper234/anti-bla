# Public research summary

[v0.1-summary.json](v0.1-summary.json) is the curated machine-readable summary for the public release. The [coverage guide](../docs/COVERAGE.md) explains what each result establishes and what remains unknown.

Raw provider streams, local fixture artifacts, filesystem paths, internal coordination logs and tool downloads are deliberately excluded from this repository. The technical guides retain names of historical local records for traceability. Their presence in a guide does not imply the raw record is included here.

The original qualification covered pinned BLA/REA source and independently authored fixtures. Source inventory, selected parser recovery, actual runtime observation and full semantic recovery are separate claims. Missing providers, rejected attempts and partial results never become PASS.

See [research and reproduction](../docs/RESEARCH.md) for the portable suite, the explicit research prerequisites and the scope of the published harnesses.
