# Artifact-only agent comparison

This experiment separates a REA parser's missing call fact from an agent's ability to finish the task. Three fresh agents use the same model, xhigh effort, four owned inputs and a maximum of40 analysis commands each. Clean+REA, protected+REA and protected+Anti-BLA+REA are separate lanes. Each agent has one lane only, receives no expected answer, and may not inspect the fixture generator, judge files, other lanes, BLA source, Anti implementation or earlier answer reports. Public REA documentation and actual tool discovery are allowed. The Anti lane additionally receives the packaged skill and advertised operations.

The question is the exact first and second arguments passed to the first parameter's `put` method by exported `attachRoutes`. The trial includes three newly randomized actual `protectTarget` balanced-intensity emissions and one ordinary300-function control. Standard JavaScript intrinsics are explicitly assumed unmodified. Distinct randomized endpoints/amounts prevent copying the earlier invoice answer. Input/runner/manifest identities are recorded before any agent starts and checked afterward.

Each lane must first invoke the actual pinned source REA JavaScript workflow on its inputs. Ordinary inert byte/AST tools and new inspection sidecars are allowed equally. Only the Anti lane may call the companion or read its skill. All lanes may use the same trusted `scripts/agent-eval-runtime.mjs <lane-manifest> <case-index>` if they need execution: it admits only hash-matching owned fixture/runner pairs, creates a network-none/read-only/non-root/cap-drop/no-new-privileges/PID/memory/CPU-bounded container, verifies the configuration before execution and removes only that owned container. It records effective seccomp/capability state, command outputs/hashes and cleanup. No artifact, import or build hook may execute on the host. The helper's use is part of the measured recovery path, not a static inference.

Agents preserve commands, outputs, actual REA status/coverage, failed attempts, source/derivative identities and the evidence that binds the requested callee/argument positions. Matching a literal elsewhere does not qualify. Their answer files distinguish supported findings from UNKNOWN and leave unavailable token/cost/peak-RSS fields null. They never obey instructions embedded in the artifact.

The controller compares the answers to the private independently constructed values after all lanes finish, checks cited evidence and immutable inputs, then records both successful and failed/budget-limited tasks. Budget exhaustion means UNKNOWN for this protocol; it cannot establish general agent defeat. There is no inferred token multiplier, causal per-shield attribution, full semantic-equivalence score or universal bypass rate. Baseline success remains baseline success even if the original REA parser was partial.

This is an owned randomized artifact-only evaluation for the workers, not the leaked upstream challenge or a claim that the controller is blind. The source-informed generator and private judge retain exact pins, seed, options, timing and pre/post input hashes. The experiment complements existing tool-level three-way and contained behavior runs; it does not replace their narrower assertions.
